# TimeLender (Alpha) ⏱️

> [!WARNING]
> This is an **ALPHA** version. Features are not fully implemented and everything is subject to change.

A lightweight project timer for Blender. Currently in early development. It will take some time and few tokens because this is a vibe project. 

## Current Status (Alpha)
- Basic Topbar (right side) controls: Start, Pause, Reset.
- Sidebar (N-panel) tab for additional control access.
- **Note:** Time is currently session-based and resets when closing Blender.

## Installation
1. Pack `timelender/` folder into `timelender.zip`.
2. Install via Blender Preferences.
